# Shivam's Resume

View the resume online: [svmgarg.github.io/resume](https://svmgarg.github.io/resume/).

The site displays the resume PDF (`Shivam_Resume.pdf`) in the browser and provides a download link. Desktop browsers use their built-in PDF viewer; mobile devices render the pages with PDF.js.

## Deployment

The site is hosted on GitHub Pages. Pushing to the `main` branch triggers the GitHub Actions workflow in `.github/workflows/deploy.yml`, which publishes the repository contents.
